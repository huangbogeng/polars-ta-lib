# Security Policy

## Supported versions

The latest 0.1.x release receives security fixes.

## Reporting a vulnerability

Please use GitHub's private security advisory flow:

https://github.com/huangbogeng/polars-ta-lib/security/advisories/new

Do not open a public issue for a vulnerability. Include:

- affected version;
- a minimal reproduction;
- the expected and actual behavior;
- any relevant platform or dependency details.

We will acknowledge the report and coordinate a fix and disclosure.
